ESP8266 WiFi SoC предлагает полное и автономное сетевое решение Wi-Fi; его можно использовать для размещения приложения или для разгрузки сетевых функций Wi-Fi от другого процессора приложений.

Когда ESP8266 размещает приложение, оно загружается непосредственно с внешней флэш-памяти. Имеет встроенный кеш для повышения производительности системы в таких приложениях. В качестве альтернативы, выступая в качестве адаптера Wi-Fi, беспроводной доступ в Интернет может быть добавлен к любой конструкции на основе микроконтроллера с простым подключением через интерфейс UART или мостовой интерфейс ЦП AHB.

ESP8266EX — один из самых интегрированных чипов WiFi в отрасли; он объединяет антенные переключатели, радиочастотный балун, усилитель мощности, малошумящий приемный усилитель, фильтры, модули управления питанием, требует минимальной внешней схемы, и все решение, включая интерфейсный модуль, спроектировано так, чтобы занимать минимальную площадь печатной платы.

ESP8266EX также включает улучшенную версию 32-разрядного процессора Tensilica серии L106 Diamond со встроенной памятью SRAM, помимо функций Wi-Fi. ESP8266EX часто интегрируется с внешними датчиками и другими устройствами для конкретных приложений через свои GPIO; коды для таких приложений приведены в примерах в SDK.

Сложные функции системного уровня включают быстрое переключение контекста сна/бодрствования для энергоэффективного VoIP, адаптивное смещение радиосигнала для работы с низким энергопотреблением, расширенную обработку сигналов, подавление паразитных сигналов и функции сосуществования радио для обычных сотовых сетей, Bluetooth, DDR, LVDS, Устранение помех ЖК-дисплея.

SDK на основе платформы Интернета вещей ESP8266 предлагает пользователям простой, быстрый и эффективный способ разработки устройств Интернета вещей. В этом руководстве по программированию представлен обзор SDK, а также подробная информация об API. Он написан для разработчиков встраиваемого программного обеспечения, чтобы помочь им программировать на платформе IoT ESP8266.
